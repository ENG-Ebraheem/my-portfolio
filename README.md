# 🎓 Ebraheem Al-moqbily — Portfolio & Blogfolio

A modern, highly crafted developer portfolio website built for **Ebraheem Al-moqbily** (Senior 4th-Level Information Technology student & Software Engineer). 

Inspired by the design quality, Bento Grid layout, and interactive UX of **[Braydon Coyer](https://www.braydoncoyer.dev/)**.

---

## ✨ Features & Design Highlights

1. **Floating Pill Navigation Bar**
   - Centered, backdrop-blur frosted glass navigation.
   - Built-in sound effects toggle (Web Audio API synthesised sounds).
   - Instant Dark / Light theme toggle with `localStorage` memory.
   - Real-time scrollspy active link indicator.
   - Mobile responsive drawer with smooth entrance animation.

2. **Hero Section & Interactive Photo Fan-Out**
   - Personal photography integration using Ebraheem's provided photo (`assets/images/ebraheem.jpg`).
   - 3D interactive photo stack that tilts with mouse cursor movement and fans out smoothly on hover or tap.
   - Live availability badge with animated green pulsing radar dot.
   - Quick action buttons: "View Selected Work", "Let's Talk", and one-click "Copy Email".

3. **Signature Bento Grid Showcase**
   - Modular, unequal card grid displaying:
     - **Card 1 (Span 2):** Information Technology Academic Degree & Mission statement.
     - **Card 2 (Span 1):** Real-time working digital clock with UTC+3 timezone indicator.
     - **Card 3 (Span 1):** Coding Mood / Status widget with animated CSS audio equalizer bars.
     - **Card 4 (Span 2):** Core Tech Stack pill matrix (TypeScript, React, Python, PostgreSQL, Docker, Linux).
     - **Card 5 (Span 2):** Engineering Philosophy & software craft principles.
   - Dynamic radial gradient glow following cursor coordinates on every card.

4. **Featured Projects & Deep Dive Modals**
   - Interactive category filtering tabs: *All Projects*, *Full-Stack Web*, *IT & Infrastructure*, *Systems & Python*.
   - Project cards featuring simulated terminal/browser mockups.
   - Detailed modal popups containing problem statements, architectural solutions, and key technical specifications:
     - **CampusIT Helpdesk & Asset Management System** (College capstone project).
     - **CloudVault** (Zero-trust secure cloud storage & file sharing).
     - **SmartClinic** (EHR medical records & appointment booking platform).
     - **NetPulse** (Real-time network telemetry & diagnostic dashboard).

5. **Developer Toolbox (Skills Matrix)**
   - Categorized into Frontend & UI, Backend & Data, and IT & Infrastructure.
   - Animated skill mastery progress bars.

6. **Timeline & Academic Journey**
   - 4th-level Senior IT student coursework and academic achievements.
   - Practical software engineering and freelance experience.

7. **Articles & Technical Insights ("Blogfolio")**
   - Technical articles on Node.js/TypeScript APIs, Linux/Docker for developers, and IT college reflections.
   - Click-to-read modal dialog with full, distraction-free reading experience.

8. **Interactive Contact & Rotating Quotes**
   - Direct message contact form with real-time feedback and toast notifications.
   - Braydon Coyer signature rotating footer quote ticker with famous software engineering aphorisms.

## 🚀 Getting Started

### Option 1: Double Click or Direct Browser
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Python Local Server
Run:
```bash
python server.py
```
This will start a local server at `http://localhost:8080` and automatically open your browser.

### Option 3: Node.js / NPM
Run:
```bash
npm start
```

## 🌐 Free 1-Click Deployment

- **Vercel / Netlify**: Drag and drop this folder onto the Vercel or Netlify dashboard.
- **GitHub Pages**: Push this repository to GitHub and enable Pages in repository settings under the `main` branch.
